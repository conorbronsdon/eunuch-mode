# Launch video

A 22-second square launch parody made using [brag](https://github.com/latent-spaces/brag) and [Hyperframes](https://github.com/heygen-com/hyperframes).
The sample conversation is authored illustration, not recorded product execution.

## Reproduce

Requires Node.js 22+, FFmpeg and a Chromium-compatible browser.

```bash
cd brag-output/composition
npx hyperframes@0.8.98 check
npx hyperframes@0.8.98 render --quality delivery --fps 30 --output ../brag.mp4
ffmpeg -y -ss 4.3 -i ../brag.mp4 -frames:v 1 -q:v 2 ../brag.jpg
```

If your browser is not detected, set `HYPERFRAMES_BROWSER_PATH` to its executable.
After rendering, bake the chosen settled title poster as frame zero:

```bash
cd ..
ffmpeg -y -i brag.mp4 -i brag.jpg -filter_complex "[0:v][1:v]overlay=0:0:enable='eq(n,0)'[v]" -map "[v]" -map '0:a?' -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a copy -movflags +faststart brag.poster.mp4
mv brag.poster.mp4 brag.mp4
```
