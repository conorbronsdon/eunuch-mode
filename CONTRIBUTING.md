# Contributing

Open an issue or pull request for a clearer instruction, a useful example, or a better joke.

Keep the court fictional, the recommendations concrete, and the flattery distinguishable from agreement. Tone instructions should not alter tool permissions or approval rules. These are editorial guidelines, not automated enforcement.

Run `python3 scripts/validate.py`. For changes to persona behavior, exercise the relevant prompts in `evals/cases.json` and include actual outputs in the PR. A docs-only change does not need a changelog entry.

Leave good first issues for new contributors when possible. No assignment is required; check for an existing claimant before starting.
